# WOT Club — GitHub Pages Landing

Готовый адаптивный лендинг в стиле предоставленного оформления WOT Club.

## Структура

- `index.html` — разметка сайта
- `styles.css` — весь дизайн
- `script.js` — мобильное меню и год в footer
- `assets/wot-club-reference.png` — ваше исходное оформление

## Как опубликовать на GitHub Pages

1. Создайте репозиторий на GitHub, например `wot-club`.
2. Загрузите в корень репозитория:
   - `index.html`
   - `styles.css`
   - `script.js`
   - папку `assets`
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
5. Нажмите **Save**.
6. Через некоторое время GitHub даст адрес вида:
   `https://ВАШ-ЛОГИН.github.io/wot-club/`

## Что обязательно заменить

В `index.html` найдите:

```html
https://www.youtube.com/
https://t.me/
```

и замените их на ссылки на ваши реальные каналы.

## Важно

Сейчас один загруженный вами скриншот используется как визуальная основа карточек и hero-блока.
Если у вас есть отдельные PNG/JPG исходники баннера, логотипа и превью видео, их можно положить в `assets` и заменить ссылки в CSS — тогда сайт будет выглядеть намного ближе к оригинальному оформлению канала.
